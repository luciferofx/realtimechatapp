## 🌟 About The Project

**Real-Time Chat App** is a lightweight web-based chat application built with **Node.js, Express.js, and Socket.IO**.

It allows multiple users to communicate instantly through a clean and responsive interface without requiring a traditional database.

Perfect for learning **WebSockets, real-time communication, Node.js, and Socket.IO**.

---

## ✨ Features

* 💬 **Real-Time Messaging**
* ⚡ **Instant Message Delivery**
* 👥 **Multiple Users**
* 🔌 **Socket.IO WebSockets**
* 🚀 **Node.js Backend**
* 🌐 **Express.js Server**
* 📱 **Responsive Interface**
* 🪶 **Lightweight Architecture**
* 🗄️ **No Database Required**

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/luciferofx/realtimechatapp.git
```

### 2️⃣ Enter the Project

```bash
cd realtimechatapp
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Server

```bash
node server.js
```

If your project has a start script, you can also use:

```bash
npm start
```

### 5️⃣ Open the Application

Open your browser and visit:

```text
http://localhost:3000
```
